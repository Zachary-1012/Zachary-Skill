# TrendHub v1.5.2 Public Web Hotfix

Status: **release-ready; not complete until the public phone view is verified.**

This patch retains the v1.5.1 Agent-native capability set and fixes the public Web Console acceptance failure discovered on iPhone:

- The navigation is a compact top bar and closed drawer by default on phone widths.
- The menu can only open after the user activates the accessible menu button.
- Navigation clicks and iOS back-forward restoration close the drawer before content is shown.
- HTML, CSS, and JavaScript have an explicit `v=1.5.2` asset identity, while the gateway sends mutable shell files with `Cache-Control: no-store` and `X-TrendHub-Web-Version: 1.5.2`.

## Required evidence before completion

1. The public `/health` response reports `version: 1.5.2` and `tools: 21`.
2. The public HTML response exposes `X-TrendHub-Web-Version: 1.5.2`.
3. An iPhone-size browser opens on content, not a full-screen navigation grid; opening and selecting a menu item returns to content.
4. Main CI, release gate, Remote MCP smoke, and official Registry publication are green.

The v1.5.1 release/tag/assets are not overwritten. If rollback is necessary, point Railway to the verified v1.5.1 deployment rather than mutating history.
