# TrendHub Remote Privacy Notice

_Last updated: 2026-09-17_

TrendHub Remote is a public, read-oriented MCP endpoint for trend intelligence. **No TrendHub account is required.**

## What the TrendHub application does not intentionally collect

The hosted application does not intentionally collect or persist advertising identifiers, model prompts, private cookies, usernames, account identifiers, user profiles, or visitor IP addresses into TrendHub application storage. Tool arguments are processed in memory only as needed to fulfill the request.

Trend history stored by the service consists of public-source trend evidence and operational Source Reliability metadata. It is used to support lifecycle, velocity, persistence, diffusion, reliability, and lead-time analysis; it is not used to build user profiles.

## Hosting infrastructure

TrendHub Remote runs on **third-party cloud infrastructure**. The hosting provider and network intermediaries may process connection metadata such as IP address, timestamps, and request metadata under their own infrastructure and security policies. TrendHub does not use that infrastructure data for advertising or user profiling.

## Third-party public sources

When a tool retrieves a public source, TrendHub makes the outbound request from the hosted service. Source availability, rate limits, content, and source terms remain controlled by the respective third-party services. The public hosted edition does not use a visitor's private Xiaohongshu cookie; Xiaohongshu account-enhanced features remain a local-edition capability when a user explicitly configures their own cookie on their own machine.

## Local edition

The open-source local edition remains available from the public repository and is designed to run on the user's own machine. It does not require a TrendHub central account or model API key.
