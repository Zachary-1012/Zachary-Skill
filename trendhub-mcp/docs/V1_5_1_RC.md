# TrendHub v1.5.1 Release Candidate

Status: **unpublished RC**. This branch is not production and must not create a tag, GitHub Release, Railway deployment, Registry update, or marketplace publication.

## Scope

v1.5.1 adds the Agent-native capability expression layer on top of the v1.5.0 production contract:

- MCP Resources for methodology, sources, capability registry, reliability, and bounded platform history.
- A canonical capability namespace registry while retaining the 21-tool compatibility facade.
- A unified `TrendHubResult<T>` evidence envelope for new capabilities; legacy tool response shapes remain unchanged.
- Progressive Skill 2.0 workflows and policy files.
- Read-only page context / WebMCP adapter and MCP App descriptors, without claiming host support that is not verified.
- Deterministic live-skill policy, capability routing, and task state contracts.
- OTel-compatible local metric naming with no exporter, remote telemetry, SigNoz, Uptime Kuma, or other heavy runtime dependency.

## Honest boundaries

The v1.5.1 RC does not claim proprietary firehose coverage, private platform access, long-lived real-user accuracy, or a fully interoperable MCP Tasks extension. Tasks remain a typed foundation until durable storage and the current protocol extension have an end-to-end compatibility test. Catalogued sources remain distinct from live sources.

Production and Official MCP Registry metadata remain v1.5.0. The existing v1.5.0 tag/release is immutable and is not rewritten.

## Verification

Run `npm run release:gate`. The gate checks the RC metadata, preserves 21 tools, builds TypeScript, exercises deterministic tests, performs the stdio smoke handshake, and checks that stable distribution metadata remains v1.5.0.
