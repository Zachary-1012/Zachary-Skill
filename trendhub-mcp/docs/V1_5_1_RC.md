# TrendHub v1.5.1 Release

Status: **published and deployed**.

v1.5.1 is the stable release after the v1.5.0 production baseline. The immutable v1.5.0 tag/assets are not rewritten, and v1.4.5 remains forbidden.

## Included

- MCP Resources for methodology, sources, capabilities, reliability, and bounded platform history.
- Canonical capability namespaces with the existing 21-tool compatibility facade preserved.
- Unified TrendHubResult evidence/reliability/confidence/limitations/trace envelope for new capabilities.
- Skill 2.0 progressive-disclosure workflows and evidence policies.
- Read-only page context adapter and MCP App descriptors with explicit host-support boundaries.
- Fluid responsive Web Console shell for desktop, tablet, and phone widths.
- Deterministic live-skill policy, intent routing, typed task-state contracts, and local OTel-compatible metric shape.

## Honest boundaries

This release does not claim proprietary firehose coverage, private platform access, long-lived real-user accuracy, or a fully interoperable MCP Tasks extension. Catalogued sources remain distinct from live sources; access modes remain explicit.

## Verification

Main CI, stable release, Railway deployment, and the 21-tool package gate passed. Registry publication waits for the verified public health/MCP contract.
