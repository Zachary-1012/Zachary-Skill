# Content creation

Use this workflow when the user asks to create, draft, adapt, schedule, review, or improve content.

1. Create or open one persistent content project in the TrendHub Content Studio.
2. Capture the subject, objective, audience, platform, format, voice, constraints, and explicit user facts.
3. Call `get_content_brief` for scoped trend Evidence and a production structure. Do not inject the whole research library.
4. Separate verified facts, creative interpretation, and unknowns. Mark unknown factual claims `【待核验】`.
5. Use the person's current host AI, or their configured local/open model, to return a complete editable artifact. Do not return only steps.
6. Keep the draft editable and preserve its evidence state, AI provider/model label, review stage, schedule, and next action.
7. Review factuality, originality, audience fit, platform fit, accessibility, brand fit, and compliance before marking ready.
8. Publishing remains a deliberate user action unless a separately authorized publishing integration exists.
9. Record only observed or user-entered results. Evaluate before promoting a pattern into reusable learning.

One approved evidence core may produce multiple platform-specific artifacts, but each artifact must adapt its grammar without changing facts.
